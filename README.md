
# Kay's Learning Hub

**Making Maths Fun and Easy.**

Kay's Learning Hub is a Mathematics tutoring platform providing online and onsite learning support for students in Grades 4–12 in Lagos, Nigeria.

The website serves as a professional digital portfolio for the tutor, showcasing her educational background, tutoring services, learning philosophy, and contact information.

- Professional homepage and tutor introduction
- About the tutor and educational background

## Getting Started

To run the website locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/kays-learning-hub.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server or your preferred local development server.
